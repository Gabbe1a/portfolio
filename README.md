# Портфолио

Личный сайт Михаила Табунщикова. Next.js (App Router), TypeScript, Tailwind. Русский на `/`, английский на `/en`.

## Локально

```bash
npm install
npm run dev
```

Сборка и прод-сервер на порту 3000:

```bash
npm run build
npm start
```

## Docker

```bash
docker compose up --build
```

Сайт откроется на `http://localhost:3000`.

Пароли и `.env` в репозиторий не кладутся.
